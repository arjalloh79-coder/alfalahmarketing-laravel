# Phase 4 Proposal: Real Bilingual Site Infrastructure

**Objective:** Replace Google Translate widget with native EN/FR routes and proper localization.

**Current State:** Single-language site (EN) with Google Translate overlay widget.

**Target State:** 
- EN site at `/` (root)
- FR site at `/fr/...` (prefixed routes)
- Proper translations in `lang/en` and `lang/fr`
- hreflang alternates for SEO
- Localized CTAs (WhatsApp numbers, messages)

---

## Two Approaches: Which One?

### Option A: `mcamara/laravel-localization` Package ✅ RECOMMENDED

**Pros:**
- Handles URL prefix routing automatically (`/en/`, `/fr/`)
- Middleware manages locale detection (URL → session → cookie)
- `trans()` and `transChoice()` helpers work out-of-box
- Route group `@group` macro simplifies setup
- Proven package (Laravel ecosystem standard)
- Minimal code changes needed

**Cons:**
- External dependency (adds composer package)
- Default uses `/en/`, `/fr/` (we want `/` for EN, `/fr/` for FR)
- Requires middleware + route adjustments

**Implementation:**
```php
// config/laravellocalization.php
'supportedLocales' => ['en' => 'English', 'fr' => 'Français'],
'useAcceptLanguageHeader' => false,
'hideDefaultLocaleInURL' => true, // Keep EN at /
```

---

### Option B: Native Route Groups + Route Model Binding

**Pros:**
- No external dependencies
- Full control over URL structure
- Lighter weight
- Can be exactly what we need

**Cons:**
- More manual setup (middleware, helper functions)
- Route duplication (need to define routes for both languages)
- No automatic locale detection
- More code to maintain

**Implementation:**
```php
// routes/web.php
Route::group(['prefix' => ''], function () {
    // EN routes at /
    Route::get('/', [HomeController::class, 'index'])->name('home');
    Route::get('/contact', [ContactController::class, 'index'])->name('contact');
    // ...
});

Route::group(['prefix' => 'fr'], function () {
    // FR routes at /fr/...
    Route::get('/', [HomeController::class, 'index'])->name('home.fr');
    Route::get('/contact', [ContactController::class, 'index'])->name('contact.fr');
    // ...
});
```

---

## Recommendation: **Option A (mcamara/laravel-localization)**

**Why:**
1. Proven, maintained package
2. Handles route generation automatically
3. Works with language switcher (no manual routing)
4. SEO-friendly (hreflang auto-generated)
5. Minimal code bloat

**Custom config for your setup:**
- English at `/` (no prefix)
- French at `/fr/` (with prefix)
- Automatic locale detection + switching

## Implementation Plan (Phase 4)

### Step 1: Install & Configure Package
```bash
composer require mcamara/laravel-localization
publish config
```

### Step 2: Create Language Files
```
lang/en/messages.php      (buttons, labels, nav)
lang/en/pages.php         (homepage content)
lang/en/services/         (6 service pages)
lang/en/contact.php       (contact page)
lang/en/about.php         (about page)

lang/fr/messages.php      (translated)
lang/fr/pages.php         (translated - WEST AFRICAN FRENCH)
lang/fr/services/         (translated)
lang/fr/contact.php       (translated)
lang/fr/about.php         (translated)
```

### Step 3: Update Views
Replace hardcoded strings with `{{ trans('messages.button_submit') }}`.

### Step 4: Add Language Switcher
```html
<a href="{{ LaravelLocalization::getLocalizedURL('en') }}">🇬🇧 EN</a>
<a href="{{ LaravelLocalization::getLocalizedURL('fr') }}">🇫🇷 FR</a>
```

### Step 5: SEO Setup
- hreflang alternates (auto-generated by package)
- Dynamic `<html lang="{{ app()->getLocale() }}">`
- Localized meta tags (titles, descriptions, OG locale)
- Bilingual sitemap (`sitemap.xml` lists both `/page` and `/fr/page`)

### Step 6: Localized CTAs
- FR pages → Guinea WhatsApp + FR message
- EN pages → Both Guinea + USA numbers

### Step 7: Remove Google Translate
- Delete Google Translate script
- Remove `googtrans` cookie logic
- Remove related CSS (display:none styles)

## Content Strategy: West African Business French

**Not literal translation.** Use natural Guinean/West African French for:
- Service names (digital agency language, not textbook)
- CTAs (urgency & local relevance)
- Testimonials (friendly, conversational)

**Examples:**
```
EN: "Digital Marketing Agency"
FR: "Agence Marketing Digital" or "Agence de Publicité"

EN: "Get your website built today"
FR: "Lancez votre présence en ligne maintenant" (not "Faites construire votre site")

EN: "Schedule a consultation"
FR: "Réservez une consultation" or "Fixez un rendez-vous"
```
